## Project Details
- **Project Name:** FitBuddy – AI Fitness Plan Generator using Gemini Models
- **Purpose:** Generate personalized 7-day workout plans and nutrition tips using AI, and refine them using user feedback.

## Suggested Demo Flow
1. **Introduction** – name, project title, purpose
2. **Tech stack** – FastAPI, Gemini 1.5 Pro & Flash, SQLite, Jinja2
3. **Start server** – run `uvicorn app.main:app --reload`
4. **Home page** – fill in details and click Generate Plan
5. **Result page** – show the 7-day plan and nutrition tip
6. **Feedback** – enter User ID and feedback, show the updated plan
7. **Admin page** – open View All Users, show original vs updated plans
8. **Conclusion** – summary and future scope
